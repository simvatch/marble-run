# Marble Run

## Why I made it

I made this project for Half-life week 2 inspired by the marble run tutorial. I decided I wanted to build a racing track for two different marbles to go down at the same time.
The first few images are the whole project and what I intended it to be. However, due to expensive parts it now only has one track. Hopefully in the future I could maybe build the full project I had planned.
